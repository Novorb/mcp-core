The package root (`@novorb/mcp-core`) re-exports the logger (except `redactSecrets` and `maskPii`, which are on `@novorb/mcp-core/logger` only; `registerSecretValues` is on both), retry, pagination, http-client, server, bootstrap, tools, env, data-store, net and url-path surfaces, the auth basics (`apiKeyVerifier`, `HttpAuthOptions`), the limits (`resolveLimits`, `DEFAULT_LIST_PAGE_SIZE`, `DEFAULT_MAX_RESULT_BYTES`, `DEFAULT_MAX_RESULT_ITEMS`, `DEFAULT_MAX_TOOL_INPUT_ELEMENTS`), list pagination (`paginateLists`, `pageListResult`, `LIST_RESULT_KEYS`), protocol errors (`toProtocolError`), protocol logging (`enableProtocolLogging`, `protocolLoggingEnabled`, `toMcpLoggingLevel`, `runWithRequestContext`, `currentRequestContext`, `requestEra`, `supportsClientFeature`, ...), the client input types, the resources, prompts, notifications, task-store, task-tools and request-state surfaces, `ExpressAdapterUnavailableError` and `EXPRESS_PEERS_MISSING`, plus `startMcpServer`, `resolveTransportMode`, `DEFAULT_MAX_BODY_BYTES` and the `ServerFactory`, `RequestContext`, `TransportHandle`, `TransportMode` and `TransportOptions` types from transport. `createRequestHandler`, `bearerMatches`, `resolveHttpAuth`, `ServerOrFactory` and `McpRequestHandler` come from `@novorb/mcp-core/transport` only; the Express adapter only from `@novorb/mcp-core/express` (it loads express).
